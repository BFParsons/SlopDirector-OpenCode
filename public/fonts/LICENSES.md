# Bundled fonts

- DejaVu Sans / Sans Bold — DejaVu Fonts licence (Bitstream Vera + public-domain additions).
- Liberation Sans / Serif / Mono (Regular, Bold) — SIL Open Font License 1.1 (Red Hat).
- Noto Sans / Noto Serif (Regular, Bold) — SIL Open Font License 1.1 (Google).
- Jost (Regular, Medium, Bold) — OFL 1.1 (indestructible type). Stands in for Futura.
- Montserrat (Light, SemiBold, Black) — OFL 1.1 (Julieta Ulanovsky et al.). Stands in for Gotham / Avenir.
- Oswald (Light, Bold) — OFL 1.1 (Vernon Adams et al.). Stands in for Trade Gothic Bold Condensed / Tungsten.
- Bebas Neue — OFL 1.1 (Dharma Type). Used by MrBeast thumbnails.
- Anton — OFL 1.1 (Vernon Adams). Used by MrBeast captions; stands in for Impact / Gunplay-style display.
- Cinzel (Regular, Bold) — OFL 1.1 (Natanael Gama). Stands in for Trajan.
- Playfair Display (Regular, Bold) — OFL 1.1 (Claus Eggers Sørensen). Stands in for Didot / the A24 serifs.
- EB Garamond (Regular, Bold) — OFL 1.1 (Georg Duffner, Octavio Pardo). Stands in for Garamond / Apple Garamond.
- Cormorant Garamond (Regular, SemiBold) — OFL 1.1 (Christian Thalmann).
- Libre Franklin (Bold, Black) — OFL 1.1 (Impallari Type). Stands in for Franklin Gothic / Balto.
- Libre Baskerville (Regular, Bold) — OFL 1.1 (Impallari Type). Stands in for Baskerville.
- Courier Prime (Regular, Bold) — OFL 1.1 (Quote-Unquote Apps). Stands in for Courier / American Typewriter.
- Zilla Slab (Regular, Bold) — OFL 1.1 (Typotheque for Mozilla). Stands in for Archer.
- Michroma — OFL 1.1 (Vernon Adams). Stands in for Eurostile Extended.
- Nunito (Regular, Bold) — OFL 1.1 (Vernon Adams et al.). Stands in for DIN Next Rounded.
- Archivo Expanded Bold (instanced from Archivo wdth 125 / wght 700) — OFL 1.1 (Omnibus-Type). Stands in for Helvetica Extended.
- Permanent Marker — Apache License 2.0 (Font Diner).

The variable-font families were instanced to static weights with fontTools
(varLib.instancer); the OFL requires that modified versions keep the licence and
are not sold on their own. All may be embedded and redistributed.
